# Smart System for Sustainable Product Recommendation
A web-based application that evaluates product sustainability, displays health and safety information, and recommends eco-friendly alternatives using product data.

## About the Project
A web-based application designed to help users identify sustainable products and discover eco-friendly alternatives.

## Features
- Search products by name or brand
- Eco-friendliness score
- Health and safety rating
- Environmental impact analysis
- Eco-friendly product recommendations

## Database
- MongoDB
- MySQL
- Product information storage and management
- Database operations for retrieving product details

## Objective
To help users make informed and environmentally responsible product choices.
